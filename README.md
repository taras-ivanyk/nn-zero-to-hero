# Neural Networks: Zero to Hero — From Scratch

My implementations of **Andrej Karpathy’s “Neural Networks: Zero to Hero”** lecture series, built independently from scratch.

The goal of this repository is to demonstrate a practical understanding of how neural networks and modern language models work by **implementing the concepts rather than simply following pre-built libraries**.

### Topics covered

* Neural networks from scratch
* Automatic differentiation & backpropagation
* Multilayer perceptrons (MLPs)
* Character-level language models
* Batch normalization
* Embeddings
* Recurrent neural networks
* Transformers
* Self-attention
* GPT architecture
* Training and inference
* PyTorch implementations

Each section contains my own implementation, experiments, and notes based on the corresponding lecture.

**Course:** Andrej Karpathy — Neural Networks: Zero to Hero
**Focus:** Understanding and implementing the underlying mechanisms from first principles.
